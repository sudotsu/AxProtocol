## 📋 DETAILED FIXES

### FIX 1: Domain Source of Truth
**Problem:** DOMAINS hardcoded in app_axp.py causes config drift with DomainConfig.json

**Fix:**
```python
def load_domains_from_config() -> List[str]:
    """Read domains from DomainConfig.json to avoid config drift."""
    if DOMAIN_CONFIG.exists():
        with open(DOMAIN_CONFIG, 'r') as f:
            config = json.load(f)
        return list(config.get('domains', {}).keys())
    # Fallback to defaults if config missing
    return ["marketing", "technical", ...]

DOMAINS = load_domains_from_config()  # Source of truth
```

**Impact:** Single source of truth, no config drift

### FIX 2: Formalized Detector API
**Problem:** Using private `_score_all_domains()` method

**Fix:**
```python
# BEFORE
scores = detector._score_all_domains(objective)  # Private API

    # Fallback for backwards compatibility
    scores = detector._score_all_domains(objective)
```

```python
def sanitize_filename(filename: str) -> str:
    filename = re.sub(r'[<>:"/\\|?*]', '_', filename)
    filename = re.sub(r'[\x00-\x1f\x7f]', '', filename)
    return filename[:200]  # Limit length
```
